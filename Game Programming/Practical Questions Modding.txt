So how did the first Saints Row extractor exist?
There are three real sources of truth, and modders usually combine all three.
1️⃣ The executable is the parser (this is the big one)
The game must do the following at runtime:
Open vpp_pc
Read header
Read file table
Seek to offsets
Decompress (if needed)
Hand data to subsystems (renderer, audio, etc.)
That logic cannot be hidden.
So the first extractor writers:
opened SaintsRowTheThird.exe
loaded it in IDA / Ghidra
searched for strings like:
"vpp_pc"
"VPP"
error messages like "failed to load package"
Once you find:
Copy code
C
LoadVPP(const char* filename)
You’re basically home.
The executable is the documentation.
2️⃣ Binary structure reveals itself faster than you think
When you open a vpp_pc in hex, it looks like chaos — but patterns jump out once you know what to look for.
Typical discoveries:
First 4 bytes = magic ("VPP\0")
Next 4 bytes = version
Repeating blocks of:
32‑bit integers
fixed‑length strings
offsets that point forward
Modders do things like:
Change a value
See if the game crashes earlier or later
Compare two versions of the same archive
This is differential reverse‑engineering.
3️⃣ Debugging the game while it loads assets
This is the “oh shit” moment for most people.
You:
attach a debugger
set a breakpoint on:
CreateFile
ReadFile
fopen
watch what happens when vpp_pc is opened
Now you literally see:
how many bytes are read
in what order
where the file table ends
where decompression starts
At that point:
writing an extractor is just re‑implementing observed behavior
No guessing. No magic.
Why it feels impossible at first
Because you’re currently seeing:
Copy code

RAW BYTES → ????
But the real flow is:
Copy code

EXE LOGIC → STRUCTURE → TOOL
Once you accept that:
formats are discovered from code
not from hex alone
Everything clicks.
How Saints Row tools specifically emerged
Historically:
Volition had previous games (SR2, Red Faction)
Formats evolved, not invented fresh
Modders recognized similarities
One person RE’d the loader
Published partial docs
Others improved tools
Community filled hash tables
This is why today it feels “easy” — but it wasn’t.
Important reality check (this matters)
Writing the first extractor is:
reverse‑engineering
not modding
not asset editing
It’s a tooling phase.
Most modders:
never do this
stand on the shoulders of 1–2 people per game
If you’re trying to do this solo from scratch: you’re playing on hard mode — but it is real engineering, not guesswork.
If you were to do it today, the sane path
Not hex‑first.
Load Saints Row exe in Ghidra
Find package loader
Identify:
header struct
file table struct
Re‑implement parser in C++ / Python
Validate by extracting filenames & sizes
Only then touch shaders
Hex editors are for:
validation
spot‑checks
corruption testing
Not discovery.
