📚 JavaScript Roadmap — Beginner → Job-Ready
Phase 1 — JavaScript Language Fundamentals (Beginner)
Book: “JavaScript: The Definitive Guide” — David Flanagan
• Classic, concise, scenario-rich
• Covers: 
• Syntax, variables, types
• Operators, control flow
• Functions & scope
• Arrays, objects, strings
• DOM basics & events
• Core built-in APIs
• Why it works: examples for multiple scenarios, shows “how JS behaves” in the real world, readable like Deitel/K&R
Alternative (slightly smaller, more beginner-friendly): “Eloquent JavaScript” — Marijn Haverbeke
• Focused exercises and examples
• Covers modern JS features (ES6+)
• Practical, project-based
Phase 2 — Intermediate / Modern JavaScript
Book: “You Don’t Know JS” series — Kyle Simpson
• Deep dive into: 
• Scope & closures
• this context
• Prototypes & inheritance
• Async / promises / async-await
• Modules & ES6+ features
• Why: teaches language mastery, not just syntax, with multiple real-world examples per topic
Phase 3 — JavaScript for Frontend Development
Book: “JavaScript and JQuery: Interactive Front-End Web Development” — Jon Duckett
• Covers: 
• DOM manipulation
• Events & forms
• Animations
• AJAX & JSON fetching
• Style: visually clear, scenario-driven, same level of clarity as PHP/Deitel books
Why: teaches practical frontend interactivity, maps perfectly to real full-stack work
Phase 4 — JavaScript for Backend / Full Stack (Node.js)
Book: “Node.js Design Patterns” — Mario Casciaro & Luciano Mammino
• Covers: 
• Node.js runtime basics
• Event loop & async programming
• Building APIs & servers
• Express framework
• REST, JSON, routing, middleware
• Project structure & modular code
• Why: critical for full-stack backend JS jobs, teaches architecture, patterns, and real scenarios
Phase 5 — Advanced JavaScript / System Thinking (Job-Ready)
Books:
• “Effective JavaScript” — David Herman 
• Patterns, pitfalls, performance, best practices
• Shows multiple approaches for the same operation
• “Designing Data-Intensive Applications” — Kleppmann 
• Backend scaling, APIs, async, database interaction
• Language-independent concepts, but maps to JS backend systems
