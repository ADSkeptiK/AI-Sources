📚 C# Roadmap — Backend Development (Beginner → Job-Ready)
Phase 1 — C# Language Fundamentals (Beginner)
Book: “C# 11 in a Nutshell” — Joseph Albahari & Ben Albahari
• Covers: 
• Variables, types, operators
• Control flow (if, loops, switch)
• Functions, methods, parameters
• Classes, structs, enums
• Basic exception handling
• Why it works: concise, examples-rich, scenario-based — teaches how C# behaves in multiple situations (like Deitel/K&R)
Phase 2 — Object-Oriented & Modern C# (Intermediate)
Book: “Programming C# 11” — Ian Griffiths
• Focuses on: 
• OOP in-depth: inheritance, polymorphism, interfaces
• Properties, events, delegates
• Exception handling patterns
• LINQ (Language Integrated Query)
• Nullable types & modern syntax (records, tuples)
• Why it matters: teaches professional coding practices and language mastery for backend logic
Phase 3 — C# Backend & Web APIs
Book: “Pro ASP.NET Core 8” — Adam Freeman
• Covers: 
• ASP.NET Core framework (current standard for backend C#)
• Building RESTful APIs
• Routing, controllers, middleware
• Dependency Injection & services
• Model-View-Controller (MVC) basics
• JSON serialization/deserialization
• Why: maps directly to real backend development jobs in C#
Phase 4 — Database Integration
Book: “Entity Framework Core in Action” — Jon P Smith
• Focuses on: 
• ORM for C# (Entity Framework Core)
• Database modeling, migrations
• CRUD operations, transactions
• Query optimization with LINQ
• Why it matters: real-world backend apps interact with a database — this gives you production-ready skills
Phase 5 — Advanced Backend / System Thinking (Job-Ready)
Books:
• “Clean Architecture” — Robert C. Martin 
• Applies to C# backend apps, teaches separation of concerns, maintainable architecture
• “Designing Data-Intensive Applications” — Martin Kleppmann 
• Advanced patterns: scaling APIs, consistency, distributed systems
